# DR0006: C# 15 required

## Summary

Darp.Results requires C# 15 or later.

## Details

`Result<TValue, TError>` is a C# 15 union of `Ok<TValue>` and `Err<TError>`. With an older language version the compiler treats it as a plain struct:

- `return new Err<string>("failed");` and `return Result.Ok(value);` do not convert to `Result<TValue, TError>`.
- `result switch { Ok<int>(var v) => ..., Err<string>(var e) => ... }` does not compile.

The rule reports once per project that references Darp.Results and compiles with C# 14 or earlier. Projects targeting `net11.0` use C# 15 by default.

## How to fix

Set the language version in the project file:

```xml
<PropertyGroup>
  <LangVersion>15</LangVersion>
</PropertyGroup>
```

The package supplies the union support types for `net10.0`, so a `net10.0` project only needs the .NET 11 SDK and the language version.

## Configuration

```ini
# .editorconfig
dotnet_diagnostic.DR0006.severity = warning
```
